# SHAR Production QC Checklists

This dataset by **[SHAR Production](https://sharprod.com/)** contains 50 authored bilingual five-step checklists for production quality control and incident closure.

`checklists.jsonl` contains one checklist per line. `checklists.json` contains the complete collection. The authored taxonomy and text use **CC-BY-4.0**. The [interactive source implementation](https://github.com/SHARProduction/production-qc-checklists) and documentation use MIT.

No client data, credentials, analytics or performance claims are included. AI assistance was used to draft and validate the material under SHAR Production's publishing responsibility.
